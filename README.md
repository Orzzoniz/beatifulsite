# beatifulsite

This repo is for making beautiful things for the web: interface demos, design effects and pages that look designed, not generated.

## References

We take ideas from design inspiration galleries and pages of design effects, starting with:

- [Inspora](https://www.inspora.design/): UI, motion and visual design shots, updated hourly

More galleries and effect pages will be added here as we use them.

Each demo credits the original designer of the concept it recreates.
